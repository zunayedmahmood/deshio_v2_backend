Social-Commerce Return / Exchange / Resale Lifecycle Test

This one-click card creates a temporary product and batch in store_id=1, sells two social-commerce orders, packs them with real barcodes, returns one, exchanges the other, resells the restored barcodes, then deletes the product batch and product.

End-to-end
  • Creates a product and a Store #1 batch with unit barcodes using the product/batch backend routes.
  • Creates two manually store-assigned social-commerce orders using the same order route as the social-commerce Amount Details page.
  • Packs each order through the same barcode fulfillment route used by the online packing page.
  • Completes the orders so barcode status and batch quantity behave like real sold stock.
  • Confirms a sold barcode cannot be packed into another order before return/exchange.
  • Runs Lookup return and Lookup exchange flows, then resells the restored returned/exchanged barcodes in a fresh social-commerce order.
  • Deletes the batch using Product > Batch deletion logic and confirms deleted-batch barcodes cannot be packed.
  • Deletes the product after its batches are gone.
